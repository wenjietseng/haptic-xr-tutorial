# haptic-xr-tutorial
A haptic demo using Meta Quest and Meta XR SDK

## Requirement
- Unity 6.3 LTS (6000.3.27f1)
- 3D (Built-in Render Pipeline) 
- XR Plug-in Management: OpenXR
- Meta XR Core SDK 207.0.1
- Meta XR Haptics SDK 207.0.1: **This is imcompatible with Meta MR Utility Kit.** If you have both, there might be problems while building the APK
- Meta XR Interaction SDK 207.0.1
- Meta XR Interaction SDK Essentials 207.0.1
- (optional) SideQuest or Meta Quest Developer Hub
